# Stripes for Obsidian

**Community themes:** *Settings → Appearance → Themes → Manage* → search **Stripes**.

**Manual:** copy `theme.css` and `manifest.json` to `<vault>/.obsidian/themes/Stripes/`.

- Dark mode uses **Night** and light mode uses **Bone**.
- Install the [Style Settings](https://github.com/mgmeyers/obsidian-style-settings) plugin to switch the dark variant to **Void** or **Blood**, or to turn off the striped headings.
