# Stripes for Discord

Works with client mods that load custom CSS: [Vencord](https://vencord.dev) and [BetterDiscord](https://betterdiscord.app).

- **Vencord:** *Settings → Themes → Online Themes*, then paste:
  `https://raw.githubusercontent.com/laktolyx-rgb/Stripes/main/ports/discord/stripes-night.theme.css`
- **BetterDiscord:** put `stripes-night.theme.css` in the themes folder (*Settings → Themes → Open Themes Folder*).

> Client mods break Discord's Terms of Service. Use them at your own risk.
