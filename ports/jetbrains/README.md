# Stripes for JetBrains IDEs

IntelliJ IDEA, WebStorm, PyCharm, GoLand, Rider, CLion, RustRover, PhpStorm, DataGrip and Android Studio.

## Install

- **Marketplace:** *Settings → Plugins → Marketplace → "Stripes"*
- **Manual:** download `stripes-jetbrains-*.zip` from the GitHub Release → *Settings → Plugins → ⚙ → Install Plugin from Disk*

Then: *Settings → Appearance → Theme → Stripes Night*. The editor color scheme switches with it.

## Build

```sh
gradle buildPlugin   # requires JDK 17+
```
