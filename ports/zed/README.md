# Stripes for Zed

**Extensions:** `Ctrl/Cmd+Shift+X` → search **Stripes** → Install. Then `theme selector: toggle` → *Stripes Night*.

**Manual:** copy `themes/stripes.json` to `~/.config/zed/themes/`.

```json
{
  "theme": { "mode": "system", "dark": "Stripes Night", "light": "Stripes Bone" }
}
```
