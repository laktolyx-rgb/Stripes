# Stripes for VS Code

> Black and white, and one drop of blood.

Four variants:

| | |
|---|---|
| **Stripes Night** | The original: charcoal `#101010`, bone text, blood accent |
| **Stripes Bone** | Light: old parchment and dried ink |
| **Stripes Void** | True black for OLED |
| **Stripes Blood** | High contrast: every token passes WCAG AAA |

## Install

- **Marketplace:** `ext install stripes-theme.stripes`
- **Open VSX** (VSCodium, Cursor, Windsurf): search "Stripes"
- Then: `Ctrl+K Ctrl+T` → *Stripes Night*

## Recommended settings

```jsonc
{
  "workbench.colorTheme": "Stripes Night",
  "window.autoDetectColorScheme": true,
  "workbench.preferredDarkColorTheme": "Stripes Night",
  "workbench.preferredLightColorTheme": "Stripes Bone",
  "editor.fontFamily": "'JetBrains Mono', 'Fira Code', monospace",
  "editor.fontLigatures": true
}
```
